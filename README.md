# Русский бильярд — Android

Первая полностью играбельная версия русского бильярда (Свободная пирамида) для Android.

## Управление
Игра работает в горизонтальной ориентации. Коснитесь/потяните в направлении, противоположном удару, и отпустите. Длина жеста определяет силу.

## Получить APK через GitHub
1. Загрузите **содержимое** этого ZIP в корень нового GitHub-репозитория.
2. Откройте вкладку **Actions**.
3. Workflow `Build Android APK` запустится после загрузки в main/master. Его также можно запустить вручную (`Run workflow`).
4. После успешной сборки откройте запуск и скачайте Artifact `RussianBilliards-APK`.
5. Внутри будет `app-debug.apk`, который можно установить на Android (может потребоваться разрешить установку из браузера/файлового менеджера).

## Что реализовано
- горизонтальный полноэкранный режим;
- 15 светлых прицельных шаров и биток;
- 6 узких луз;
- столкновения шаров, трение и отскоки от бортов;
- кий, линия прицеливания и сила удара жестом;
- 2 игрока на одном устройстве;
- подсчёт забитых шаров и победа при 8 шарах;
- возврат битка после падения в лузу.

Примечание: физика игровая и упрощённая; это не сертифицированный симулятор турнирной физики русского бильярда.
